- 每轮有实质新发现时创建一个唯一的新 Markdown 文件，不覆盖既有研究记录。
- 文件名包含北京时间日期时间、任务类型和简短主题。
- 研究 note 只包含 research/discovery 内容，不构成开发任务、产品 canonical 或发布授权。
- `main` 保持 V7 已发布基线，只读。
- 阶段性再从这些原始研究 note 汇总到 NEXT_VERSION_RESEARCH / PRODUCT_EXPERIENCE_RESEARCH；不要因为汇总失败阻塞原始研究沉淀。
